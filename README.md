# Контур · 0.1.6

Браузерная основа редактора для раскрашивания. HTML, CSS и JavaScript без сборки, внешних библиотек, сетевых запросов и сервера обработки изображений.

## Запуск

Откройте `Kontur.html` в современном браузере: это автономная версия с включёнными стилями и скриптами. Интернет для её работы не нужен.

Для публикации на GitHub Pages разместите `index.html`, `style.css`, `core.js`, `app.js` и `.nojekyll` в корне репозитория. В Settings → Pages выберите Deploy from a branch, затем main и /(root). Все ссылки на ресурсы относительные: редактор работает и в подкаталоге.

## Основной сценарий

1. Откройте PNG, JPEG, WebP или другое поддерживаемое браузером растровое изображение.
2. Выберите слой «Рисунок».
3. Нажмите W и щёлкните по цвету контура. Допуск задаёт максимальное отклонение по каналам RGBA (0–255). Без «Смежных пикселей» выделятся подходящие цвета по всему холсту. Shift добавляет, Alt вычитает области.
4. Ctrl J копирует выделенные пиксели текущего слоя на новый слой; Ctrl Shift J переносит их, удаляя с исходного слоя. Края копируются с исходной прозрачностью. При выборке с видимых слоёв копирование всё равно берёт пиксели текущего слоя.
5. Для чёрно-белого рисунка на светлой бумаге удобнее «Отделить контур от белого». Команда создаёт чёрный контур с прозрачностью, зависящей от яркости: серые сглаженные края сохраняются. Оригинал остаётся отдельным скрытым слоем. Контур защищается, а под ним создаётся слой «Цвет».
6. Рисуйте или заливайте на слое «Цвет». При образце «Видимые слои» заливка учитывает контур над текущим слоем.
7. Сохраните `.contour` для продолжения работы со слоями. Экспорт PNG объединяет только видимые слои с учётом непрозрачности и наложения; служебная подсветка выделения не попадает в экспорт.

## Сглаживание кисти

Ползунок «Сглаживание» находится под палитрой. По умолчанию включено 45%: движение кисти и ластика фильтруется по пройденному расстоянию, а штрих строится плавными квадратичными кривыми. Учитываются промежуточные события пера и мыши, если браузер их предоставляет. Чем выше значение, тем сильнее выравнивание и заметнее отставание линии от указателя. При отпускании указателя конец штриха плавно доходит до точки отпускания. При 0% линия напрямую следует точкам указателя. Настройка запоминается в этом браузере, если доступно локальное хранилище. Один штрих остаётся одним действием отмены; выделение и непрозрачность применяются ко всему штриху.

При выключенном «Сглаживать края» (по умолчанию) краевые пиксели кисти и ластика полностью непрозрачны. При непрозрачности 100% кисть кладёт выбранный цвет без смешивания с фоном. Сглаживание траектории работает независимо: форма линии остаётся плавной. Если нужны полупрозрачные края, включите «Сглаживать края». Непрозрачность ниже 100%, непрозрачность слоя и режимы наложения по-прежнему намеренно влияют на итоговый цвет.

## Работа с отдельными пикселями

Масштаб увеличен до 6400%. Выберите значение в списке над холстом или используйте Ctrl + колесо и кнопки −/+. При приближении больше 100% пиксели показываются без размытия, исходное изображение не пересчитывается. При уменьшении сохраняется обычное сглаженное отображение.

Для точных исправлений выберите «Карандаш» (P). По умолчанию его размер — 1 px: щелчок закрашивает ровно один пиксель без сглаживания. Размер и шаг клавиш [ / ] у карандаша отдельные от кисти. При перетаскивании пиксели соединяются без пропусков. Выделение, непрозрачность и отмена действуют как у кисти.

На холсте под указателем виден контур отпечатка: круг у кисти и ластика, квадрат у карандаша. Его размер учитывает масштаб. Квадрат карандаша привязан к пиксельной сетке, включая смещение чётных размеров. Контур скрывается вне холста, при перемещении рукой и при касании пальцем. Он служит только для отображения и не входит в изображение, историю или экспорт PNG.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| B, P, E, G | Кисть, карандаш, ластик, заливка |
| W, M, V | Выделение по цвету, прямоугольник, перемещение всего слоя |
| I, H | Пипетка, рука |
| Пробел + перетаскивание | Временная рука |
| Ctrl + колесо | Масштаб около курсора |
| [ и ] | Размер кисти |
| Ctrl Z | Отмена |
| Ctrl Shift Z / Ctrl Y | Повтор |
| Ctrl O | Открыть рисунок |
| Ctrl S | Сохранить проект |
| Ctrl Shift S | Экспорт PNG |
| Ctrl A / Ctrl D | Выделить всё / снять выделение |
| Ctrl J / Ctrl Shift J | Копировать / перенести выделение на слой |
| Delete / Backspace | Очистить выбранные пиксели текущего слоя |
| Escape | Снять выделение или отменить текущее перетаскивание |
| F1 | Справка |

На Mac используется Command вместо Ctrl. Команды буквенных клавиш зависят от `KeyboardEvent.code`, поэтому работают в русской раскладке на тех же физических клавишах. В полях ввода текстовые клавиши не перехватываются. Системные сочетания и отдельные зарезервированные команды браузера могут иметь приоритет.

## Слои и история

Поддержаны видимость, защита, непрозрачность, обычное наложение, умножение и экран; добавление, дублирование, удаление и изменение порядка. Двойной щелчок по имени переименовывает слой. Защищённые слои можно копировать, но нельзя изменять или удалять, пока не снят замок.

Отмена и повтор хранят до 25 действий, с бюджетом истории около 96 МБ. Для крупных документов число доступных действий уменьшается; как минимум последнее действие сохраняется. История и выделение не входят в файл проекта.

Для кисти, карандаша и ластика исходные пиксели сохраняются только в затронутых фрагментах текущего слоя размером 128 × 128 px. Во время мазка обновляется только область новых сегментов, включая края и сглаживание; остальные части холста не пересобираются. Миниатюры слоёв кешируются и пересчитываются только при изменении их пикселей. Операции изменения структуры слоёв, заливки, переноса выделения и перемещения слоя пока используют полные снимки истории.

## Ограничения первой версии

- Холст до 24 миллионов пикселей, каждая сторона до 8192 px. Суммарно до 120 миллионов пикселей слоёв, до 40 слоёв. Изображения открываются в исходном разрешении. При отказе загрузки причина отображается над холстом.
- Размер открываемого изображения до 80 МБ, файла проекта до 100 МБ.
- Только базовая круглая кисть. Нет давления пера, текстурных кистей, трансформаций выделенной области, PSD, автосохранения и восстановления несохранённой работы после закрытия браузера.
- Заливка учитывает допуск и замкнутые области; автоматическое закрытие разрывов и расширение заливки под сглаженные края пока не реализованы.
- «Отделить контур» рассчитано на тёмный монохромный рисунок на светлой бумаге. Для цветных контуров используйте выделение по цвету и перенос на слой.
- В анимированном GIF используется кадр, который декодировал браузер; работа с анимацией не поддерживается.
- Файлы обрабатываются локально. При размещении на GitHub Pages серверу передаются обычные запросы страницы и её ресурсов, но редактор не загружает туда ваши рисунки.

Проверка оптимизации и смешанной истории: `node tests/performance.test.cjs`. Проверка пиксельных операций: `node tests/core.test.cjs`. Проверка цвета кисти: `node tests/brush-color.test.cjs`. Проверка точного рисования и масштаба: `node tests/pixel.test.cjs`. Проверка сглаживания: `node tests/smoothing.test.cjs`. Регрессионный тест загрузки PNG: `node tests/import.test.cjs` (для тестового окружения нужны `jsdom` и `@napi-rs/canvas`). Самому редактору Node.js и какие-либо установленные пакеты не нужны.
